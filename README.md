# 📘 LexiFlow — دفترچه هوشمند آفلاین‌محور کلاس زبان (PWA)

یک وب‌اپلیکیشن پیشرفته (Offline-First PWA) ساخته‌شده با **React + TypeScript + Dexie (IndexedDB) + FSRS-5 + Supabase** برای یادداشت‌برداری سریع روی گوشی و لپ‌تاپ بدون نیاز به اینترنت و با همگام‌سازی ابری لحظه‌ای.

## قابلیت‌های کلیدی
- **ذخیره‌سازی ۰ میلی‌ثانیه‌ای و کاملاً آفلاین (IndexedDB):** حتی در مترو و بدون اینترنت ثبت و مرور کن.
- **۶ دسته‌بندی پویا:** کلمه، عبارت و اصطلاح، گرامر، جمله کاربردی، فعل عبارتی، تلفظ و اسپیکینگ.
- **الگوریتم علمی مرور FSRS-5:** در ۳ حالت کلاسیک (EN ➔ FA)، بافت جمله (Cloze Deletion) و تولید فعال (FA ➔ EN).
- **تکمیل هوشمند با هوش مصنوعی (Gemini Flash):** با یک کلیک معنی، فونتیک IPA، ساختار گرامر، مثال و نکات کلیدی پر می‌شود.
- **تلفظ واقعی (US / UK) + ثبت با صدا (Voice-to-Note):** دریافت صوت انسانی از Dictionary API + پشتیبانی آفلاین از مرورگر.
- **همگام‌سازی ابری امن (Supabase + RLS):** سینک دوطرفه و خودکار بین گوشی و لپ‌تاپ.
- **انتقال از گوگل شیت قبلی + خروجی Anki CSV و بکاپ JSON.**

## اجرای محلی (لپ‌تاپ)
```bash
npm install
npm run dev
```

## انتشار رایگان (Vercel) و نصب روی گوشی
1. پروژه را در یک ریپازیتوری گیت‌هاب آپلود کن.
2. در سایت `vercel.com` گزینه **Import Project** را بزن و Deploy کن.
3. لینک ساخته‌شده را در مرورگر گوشی باز کن و گزینه **Add to Home Screen / Install App** را بزن.

## فعال‌سازی همگام‌سازی ابری (اختیاری)
1. در `supabase.com` یک پروژه رایگان بساز.
2. محتوای فایل `supabase_schema.sql` را در **SQL Editor** کپی و Run کن.
3. از بخش `Settings > API` مقدار **Project URL** و **anon public key** را در تب «تنظیمات» اپلیکیشن وارد کن و با ایمیل خودت یک حساب بساز.
